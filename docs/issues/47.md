# chore: пример окружения без секретов

## Неопределённость
U-12, U-15 — секреты не должны попасть в git и не должны читаться из двух мест.

## Инварианты
Нет доменных. `process.env` только в `src/config` (S-4).

## События
Нет.

## Сделать
- `.env.example` с именами из схемы: `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `GITHUB_APP_ID`, `GITHUB_APP_PRIVATE_KEY`, `GITHUB_WEBHOOK_SECRET`
- настоящий `.env` не коммитить (уже в `.gitignore`)

## Не делать
- вторую точку чтения окружения
- переменные, которых нет в схеме

## DoD
- по примеру собирается окружение, не открывая код
- секретов в git нет
- CI не ослаблен
