## Стартовый аудит (приложение П1)

Проводится до внедрения, чтобы через месяц было с чем сравнивать. Кода ещё нет, поэтому часть цифр нулевая по определению — это и есть смысл базовой линии.

| Вопрос | Значение на старте | Что означает |
| --- | --- | --- |
| Сколько инвариантов домена сформулировано? | 16 | больше пяти: домен описан, патч применим |
| Сколько из них имеет тест? | 0 | весь объём долга по S-7 равен 16 и закрывается по мере реализации |
| Сколько `event_type` в коде? Сколько в реестре? | 0 и 22 | расхождения нет, реестр вводится до первого события |
| Есть ли импорты из домена в инфраструктуру? | 0 | границы вводятся до первой фичи, нарушений не накоплено |
| Сколько реализаций у обработки ошибок, конфига, клиента БД? | по 0, в реестре механизмов заявлено по 1 | дрейф ещё не начался |
| Сколько ждёт исполнитель решения по домену? | не измеряется | один исполнитель, очереди нет |

**Строка базовой линии:** 16 инвариантов в спеке, 0 в тестах, 0 событий мимо реестра.

Через месяц разработки к этой строке возвращаются. Ожидаемое состояние: 16 в спеке, 16 в тестах, 0 мимо реестра. Любое другое соотношение — это долг, а не «так вышло».
