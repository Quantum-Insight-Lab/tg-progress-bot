## Зачем

У Андрея в одном топике два канваса. Кружок задачи 1 на ЭКГ-патч ничего не делает: задача 1 есть и у Rhythm layer. Кружок задачи 3, номер которой в топике один, канвас Rhythm layer меняет.

## Что найдено

- Кнопка несёт номер задачи.
- Поиск идёт по всему топику.
- Две задачи с одним номером — отказ. Канвас, на котором нажали, не правится.
- Номер уникален внутри проекта. В топике с двумя проектами он повторяется законно.

## Путь

1. Кружок, слово приоритета, «в план», «в работу», «подтвердить», «вернуть» и «отменить» меняют задачу того канваса, на сообщении которого нажаты.
2. Проект берётся из этого сообщения. Номер — из кнопки.
3. Задача с тем же номером на другом канвасе топика не меняется.
4. Кто имеет право нажимать, остаётся как сейчас.
