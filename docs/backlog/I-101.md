# I-101. progress — без репозитория строка человека на канвасе не печатается

## Уже есть

- I-62 — строка человека на канвасе · INV-14 · P-4
- I-100 — канвас: задачи сверху, срез issues в раскрывающемся блоке · P-1, P-3, P-4, P-5, P-9, P-10, P-11 · B-6

## Зачем

У проекта без репозитория канвас пишет «Andrew по issues: сделал 0 · сейчас на нём 0 · дальше в репозитории 0». Считать нечего: репозитория нет. Рядом строка GitHub уже говорит «репозиторий не подключён».

## Что найдено

- Логин записан, репозитория нет — код отдаёт пустой срез и печатает нули.
- Без логина в том же случае печатается «нет сопоставления с GitHub». Сопоставлять тоже не с чем.
- Срезы issues без репозитория уже не печатаются. Раскрывающийся блок остаётся из-за одной строки человека.
- Подключённый репозиторий без issues — другой случай: нули здесь честные.

## Путь

1. Репозиторий проекта не подключён — строку человека не печатать. Ни нули, ни «нет сопоставления с GitHub».
2. Раскрывающийся блок без этой строки и без срезов issues не собирать.
3. Репозиторий подключён — строка как сейчас: нули, если issues нет; «нет сопоставления с GitHub», если логина нет.
4. Строка GitHub не меняется.
