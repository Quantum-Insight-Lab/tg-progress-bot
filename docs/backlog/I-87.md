## Зачем

Доля бэклога, CI и строка GitHub верны, пока доходят доставки и работает сверка. Сейчас не видно ни пришедшей доставки, ни несошедшейся подписи, ни того, что восстановила сверка.

## Что найдено

- URL webhook GitHub App человек ставит сам: `PUBLIC_WEBHOOK_ORIGIN` + `/github/webhook`; дошла ли первая доставка после развёртывания 30.09, по серверу не понять;
- отказы сверки по репозиториям собираются в `failures`, наружу выходит только первый;
- остаток лимита пишется событием `github.rate_observed` (A-41), в логе его нет.

## PDA

B-17 · B-5, B-13 · INV-21, INV-22 · M-8, M-17, M-26 · A-41 · события `github.reconciled`, `github.rate_observed`

## Атомы ТЗ

Нет: работа derived, её содержание — элементы PDA выше.

## Сделать

- доставка webhook: `X-GitHub-Delivery`, `X-GitHub-Event`, `action`, репозиторий и исход — записано в зеркало, повтор, пропущено; неверная подпись — `warn` без тела запроса;
- сверка по репозиторию: сколько фактов прочитано и сколько восстановлено; отказ — `error` по каждому репозиторию, а не только по первому;
- вызов API GitHub: маршрут, код ответа, длительность; остаток лимита в конце хода — `info`, ниже `GITHUB_RATE_FLOOR` — `warn`;
- токен установки и ключ App в лог не попадают.

## Не делать

## DoD

- тест: доставки с верной и неверной подписью, повтор той же доставки и отказ одного репозитория в сверке дают по строке своего уровня;
- `npm run ci` зелёный, ни одна проверка не ослаблена.
