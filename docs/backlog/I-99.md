# I-99. progress — в отчёте есть строка «Все проекты»

## Уже есть

- I-77 — отчёт: «За сутки» и «Все проекты» · P-12

## Зачем

На живом `/report` нет строки «Все проекты: было → стало · осталось», хотя на канвасе доля есть.

## Что найдено

- Проекция печатает строку, когда доля известна на обе границы суток и есть остаток.
- Сборка отчёта подставляла пустую долю и пустой остаток. Строка из-за этого не занимала место. «Бэклог» проекта тоже.

## Путь

1. Доля и остаток берутся из issues репозитория. Репозиторий в «Все проекты» входит один раз. Проект без репозитория в эту строку не входит.
2. Issue, закрытый как сделанный внутри суток, на начало суток ещё открыт. Стрелка показывает это изменение.
