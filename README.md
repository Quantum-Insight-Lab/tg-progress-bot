# Как пользоваться ботом

Бот живёт в Telegram. Задачи и канвас — в топике исполнителя. Отчёт группы — в командном топике. Всё остальное — в личке с ботом.

Чужой текст бот не разбирает и молчит. Команда — это сообщение с точным заголовком в первой строке либо кнопка под его сообщением.

Время — час `0`–`23`, сколько сейчас у вас. Имя города бот не спрашивает.

## Кто есть кто

- **Корень** — первый, кто нажал `/start`. Заводит проекты, добавляет людей, меняет настройки и репозиторий.
- **Lead** — руководитель проекта. Подтверждает задачи. В проекте, который завёл корень, корень сразу `lead`.
- **Member** — участник. Ведёт свои задачи.

Исполнителем может быть и `member`, и `lead`: у обоих свой топик и канвас.

## С чего начать

В личке с ботом:

```
/start
```

Первому бот отвечает, что он руководитель, и показывает образец нового проекта. Остальным пишет, что доступ появится, когда корень добавит их в проект.

## Новый проект

В личке, четыре строки. Описание может быть пустой строкой.

```
Новый проект
Rhythm layer
коротко, о чём проект
14
```

Дальше бот сам просит супергруппу.

## Супергруппа

Нужна супергруппа с темами. Бот — администратор с правом писать сообщения и управлять темами.

Добавьте бота в группу и нажмите «Подтвердить». Если в этой группе уже есть другой проект, новый сядет в ту же группу и тот же командный топик.

## Репозиторий

После привязки группы бот показывает репозитории установки GitHub App. Подключает руководитель. Шаг можно пропустить кнопкой «Пропустить».

Позже список открывается так:

```
Репозиторий
Rhythm layer
```

Сменить уже подключённый репозиторий может только корень.

## Командный топик

Сюда уходит общий отчёт группы. Если бот сам не спросил, откройте шаг двумя строками:

```
Командный топик
Rhythm layer
```

- **Нет** — бот создаёт топик «Отчёты».
- **Есть** — бот присылает образец. В ответ нужно всё сообщение, а не одно число:

```
Командный топик
Rhythm layer
58
```

`58` — номер топика в этой супергруппе.

## Время отчёта

Бот спрашивает сразу после командного топика. Три строки: заголовок, имя проекта, время. Сдвиг группы уже записан при создании проекта.

```
Время отчёта
Rhythm layer
09:00
```

Пока время не названо, рассылка выключена. Когда оно задано, под экраном кнопка «Выключить»: её нажимает корень. Время группы стирается, сдвиг остаётся. Кнопка гасит рассылку всех проектов этой супергруппы.

Личный `/report` работает и при выключенной рассылке.

Когда рассылка включена, бот показывает, как открыть состав.

## Участники

Человек сначала сам нажимает `/start`. Пока он этого не сделал, корень его не видит.

```
Участники
Rhythm layer
```

«Добавить» берёт человека как `member`. Корень в этот список не попадает: в новом проекте он уже `lead`.

## Логин GitHub

Бот спрашивает его у нового участника. Две строки, либо кнопка «Пропустить».

```
Логин GitHub
octocat
```

Логин один на человека, не на каждый проект. Без него задачи работают, но коммиты и PR к человеку не приклеиваются.

## Топик исполнителя

```
Топик исполнителя
Rhythm layer
```

У кого топика ещё нет, бот спрашивает:

- **Нет** — создаёт топик с именем человека и ставит туда канвас.
- **Есть** — тот же приём, что у командного топика: четыре строки, в последней номер.

```
Топик исполнителя
Rhythm layer
Максим
1811
```

Пока группа не привязана, топик пустой: канвас появится после привязки.

## Задачи

В своём топике:

```
/task починить вход
```

Задача сразу появляется на канвасе. Кнопки внутри строки:

- кружок — отправить на подтверждение руководителю, процент проекта от этого не меняется;
- «в план» и «в работу» — перенос между планом и текущими задачами;
- слово приоритета — смена приоритета;
- «подтвердить» и «вернуть» — решение руководителя;
- «отменить» — снять задачу, пока она не сделана.

Чужой топик задачу не создаёт. Подтверждает `lead`. Если в проекте один руководитель и задача его, он подтверждает её сам.

## Отчёт

`/report` в личке — проекты этого человека. `/report` в группе — все проекты этой супергруппы, одним сообщением в командный топик.

Состав отчёта не настраивается. Пустые строки бот не печатает. В отчёт не входят тихие issues, ветки и метки. Закрытые issues в блок GitHub не копируются: они уже в бэклоге.

По расписанию тот же групповой отчёт уходит в командный топик. Топики исполнителей его не получают.

## Настройки

Меняет только корень. Четыре строки: заголовок, проект, поле, значение. Поля: `имя`, `описание`, `таймзона`, `супергруппа`, `роль`.

```
Настройки
Rhythm layer
таймзона
14
```

`14` — сколько сейчас часов. Это пересчитывает сдвиг проекта и не трогает сдвиг группы.

Роль:

```
Настройки
Rhythm layer
роль
Andrew lead
```

В роли имя и слово `lead` или `member` разделяет последний пробел, поэтому `Яков Гречнев lead` тоже подходит.

Текущие значения:

```
Настройки
Rhythm layer
```

## Чего бот не делает

Проект удалить нельзя. Снять можно задачу или участника. Удаление участника снимает его незакрытые задачи.
